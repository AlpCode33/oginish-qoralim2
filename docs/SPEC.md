# تېخنىكىلىق ئۆلچەم ۋە قۇرۇلما ھۆججىتى (SPEC) — «ئۆگىنىش قورالىم»

**ھۆججەت نۇسخىسى:** 1.0.0
**نۇسخا ئۆلچىمى:** Chrome Extension Manifest V3
**ھۆججەت قۇرۇلمىسى:** 3 يادرولۇق ھۆججەت (`manifest.json`، `popup.html`، `popup.js`)

---

## 1. سىستېما ئارخىتېكتورى (System Architecture)

«ئۆگىنىش قورالىم» قىستۇرمىسى 3 ھۆججەتلىك قاتتىق تەلەپ بىلەن ئېنتېرپرايس سەۋىيەلىك ئىقتىدارنى بىرلەشتۈرۈش ئۈچۈن **قوش مۇھىتلىق ئىجرا ئەندىزىسى (Dual-Context Execution Pattern)** نى قوللىنىدۇ:

```text
┌──────────────────────────────────────────────────────────────────┐
│                        manifest.json (MV3)                       │
│  permissions: ["storage", "notifications", "alarms"]             │
│  CSP: default-src 'self'; script-src 'self'; connect-src 'none'  │
└──────────────────┬─────────────────────────────┬─────────────────┘
                   │                             │
      [Window Context: Popup UI]     [ServiceWorkerGlobalScope]
                   │                             │
                   ▼                             ▼
           ┌───────────────┐            ┌────────────────────┐
           │  popup.html   │            │ popup.js (SW قىسمى)│
           │ (RTL + CSS)   │            │ - onInstalled      │
           └───────┬───────┘            │ - onStartup        │
                   │ <script>           │ - alarms.onAlarm   │
                   ▼                    │ - notifications    │
           ┌───────────────┐            └─────────┬──────────┘
           │ popup.js (UI) │                      │
           │ - Router/Views│                      │
           │ - JSON Parser │                      │
           │ - Study Engine│                      │
           └───────┬───────┘                      │
                   │                              │
                   └──────────────┬───────────────┘
                                  ▼
                    ┌───────────────────────────┐
                    │   chrome.storage.local    │
                    │  (100% يەرلىك سانلىق بازا) │
                    └───────────────────────────┘
```

### نېمە ئۈچۈن قوش مۇھىتلىق `popup.js`؟
- `popup.js` ئىجرا قىلىنغاندا `typeof window !== 'undefined' && typeof document !== 'undefined'` ئارقىلىق مۇھىتنى ئېنىقلايدۇ.
- **ئارقا سۇپا مۇلازىمىتى (Service Worker) مۇھىتىدا:** پەقەت `chrome.runtime.onInstalled`، `chrome.runtime.onStartup`، `chrome.alarms.onAlarm` ۋە `chrome.notifications.onClicked` تىڭشىغۇچلىرى تىزىملىنىدۇ.
- **كۆزنەك (Popup Window) مۇھىتىدا:** پۈتۈن RTL يۇمشاق نېئومورفىزم كۆرۈنمە يۈزى، JSON يۈكلەش، ئۆگىنىش كارتىلىرى ۋە پرومپىت كۆچۈرۈش ماتورى ئىجرا بولىدۇ.
- نەتىجىدە **دەل 3 ھۆججەت** بىلەن ھەم Chrome غا خاتالىقسىز قاچىلىنىدۇ، ھەم تور كۆرگۈچ ئېچىلغاندا ھەقىقىي ئارقا سۇپا ئەسكەرتمىسى ئىشلەيدۇ.

## 2. سانلىق مەلۇمات قۇرۇلمىسى ۋە JSON سىخېمىسى (Data Schema)

### 2.1. يەرلىك ساقلاش قۇرۇلمىسى (`chrome.storage.local`)

ساقلاش ئاچقۇچى: `oginish_qoralim_state_v1`

```json
{
  "version": 1,
  "settings": {
    "globalReminderEnabled": true,
    "reminderIntervalMinutes": 0
  },
  "pendingStartupReminder": {
    "bookId": "book_1732000000000_a1b2",
    "bookTitle": "كىتاب نامى",
    "questionId": "q_1",
    "question": "سوئال تېكىستى",
    "answer": "جاۋاب تېكىستى",
    "reminderNote": "مۇھىم ئەسكەرتىش",
    "createdAt": 1732000000000
  },
  "books": [
    {
      "id": "book_1732000000000_a1b2",
      "title": "كىتاب نامى",
      "category": "ئومۇمىي بىلىم",
      "reminderEnabled": true,
      "createdAt": 1732000000000,
      "updatedAt": 1732000000000,
      "questions": [
        {
          "id": "q_1",
          "question": "سوئال مەزمۇنى",
          "answer": "تەپسىلىي جاۋاب",
          "importance": "ئىنتايىن مۇھىم",
          "mastered": false,
          "reviewCount": 0
        }
      ],
      "vocabulary": [
        {
          "id": "v_1",
          "term": "مۇھىم سۆزلۈك",
          "meaning": "ئېنىق مەنىسى"
        }
      ],
      "reminders": [
        {
          "id": "r_1",
          "text": "مۇھىم ئەسكەرتىش ياكى خۇلاسە پىكىر"
        }
      ]
    }
  ]
}
```

> **ئىزاھات:** `reminderIntervalMinutes` قىممىتى `0` بولسا «پەقەت تور كۆرگۈچ ئېچىلغاندا» دېگەننى بىلدۈرىدۇ؛ `60` بولسا ھەر 1 سائەتتە؛ `180` بولسا ھەر 3 سائەتتە ئەسكەرتىدۇ.

### 2.2. سۈنئىي ئەقىلدىن قوبۇل قىلىنىدىغان JSON كىرگۈزۈش سىخېمىسى

```json
{
  "bookTitle": "كىتاب ياكى دەرسلىك نامى",
  "category": "تۈرى",
  "questions": [
    {
      "question": "1-سوئال",
      "answer": "1-جاۋاب",
      "importance": "ئىنتايىن مۇھىم"
    }
  ],
  "vocabulary": [
    {
      "term": "ئاتالغۇ",
      "meaning": "ئىزاھات"
    }
  ],
  "reminders": [
    "مۇھىم ئەسكەرتىش 1"
  ]
}
```

### 2.3. كەڭ قورساق تەھلىل قائىدىسى (Resilient Parser Rules)
1. كىرگۈزۈلگەن تېكىستتىن ```json ۋە ``` بەلگىلىرى ئاپتوماتىك تازىلىنىدۇ.
2. UTF-8 BOM بەلگىسى (`\uFEFF`) ئاپتوماتىك چىقىرىۋېتىلىدۇ.
3. سىخېما ئوخشاش مەنىلىك ئاچقۇچلارنى قوللايدۇ:
   - كىتاب نامى: `bookTitle` | `title` | `name` | `bookName`
   - سوئال تىزىملىكى: `questions` | `qa` | `items` | `cards` ياكى بىۋاسىتە تىزىملىك (`Array`)
   - سوئال/جاۋاب: `question`/`q` ۋە `answer`/`a`
   - سۆزلۈك: `vocabulary` | `terms` | `words` | `glossary` (`term`/`word` ۋە `meaning`/`definition`)
   - ئەسكەرتىش: `reminders` | `notes` | `keyPoints` | `takeaways`
4. چەكلىمە قوغداش: ھەر بىر كىتابتا ئەڭ كۆپ 500 سوئال، ھەر بىر تېكىست ئەڭ كۆپ 10,000 ھەرپ بىلەن بىخەتەر چەكلىنىدۇ.

## 3. بىخەتەرلىك ئارخىتېكتورى (Security & Threat Model)

| تەھدىت تۈرى | قوغداش تەدبىرى |
| --- | --- |
| **XSS (تور بەت ئىچىگە زىيانلىق كود سىڭدۈرۈش)** | بارلىق ئىشلەتكۈچى ۋە JSON مەلۇماتلىرى پەقەت `document.createElement` ۋە `textContent` ئارقىلىق سىزىلىدۇ؛ `innerHTML` ئىشلىتىلمەيدۇ. |
| **تاشقى سانلىق مەلۇمات ئېقىپ كېتىش** | MV3 CSP دا `connect-src 'none'; default-src 'self'; img-src 'self' data:; font-src 'self';` بەلگىلەنگەن. |
| **زىيانلىق ئىجازەت كېڭىيىشى** | `host_permissions` يوق؛ `tabs`، `activeTab`، `scripting`، `cookies` رۇخسەتلىرى قەتئىي ئېلىنمايدۇ. |
| **بۇزۇلغان JSON ياكى ساقلاش خاتالىقى** | بارلىق async/sync مەشغۇلاتلار `try/catch` بىلەن ئورالغان؛ خاتالىق چىقسا پروگرامما توختاپ قالماي، ئۇيغۇرچە ئېنىق ئۇچۇر كۆرسىتىدۇ. |
| **ئەسكى ساقلاش ھالىتىنىڭ بۇزۇلۇشى** | `chrome.storage.local` دىن ئوقۇلغان سانلىق مەلۇماتلار ھەر قېتىم `normalizeState()` ئارقىلىق تەكشۈرۈلىدۇ. |

## 4. ئارقا سۇپا ئەسكەرتمە ھايات دەۋرىيلىكى (Reminder Lifecycle)

1. **تور كۆرگۈچ ئېچىلغاندا (`chrome.runtime.onStartup`):**
   - `chrome.storage.local` دىن ھالەت ئوقۇلىدۇ.
   - ئەگەر `settings.globalReminderEnabled === true` بولسا، `reminderEnabled === true` بولغان كىتابلار تاللىنىدۇ.
   - تاللانغان كىتابلار ئىچىدىن تېخى ئىگىلەنمىگەن (`mastered === false`) بىر سوئال (ياكى ئىختىيارىي سوئال) تاللىنىپ `pendingStartupReminder` غا ساقلىنىدۇ.
   - `chrome.action.setBadgeText({ text: '1' })` ۋە `chrome.action.setBadgeBackgroundColor({ color: '#1E5FE3' })` ئورنىتىلىدۇ.
   - يەرلىك `data:image/png;base64,...` سىنبەلگىسى بىلەن `chrome.notifications.create` چاقىرىلىپ سىستېما ئۇقتۇرۇشى كۆرسىتىلىدۇ.
2. **قەرەللىك ئەسكەرتمە (`chrome.alarms`):**
   - ئىشلەتكۈچى `60` ياكى `180` مىنۇت تاللىغاندا `oginish_qoralim_periodic` ناملىق alarm قۇرۇلىدۇ.
   - ۋاقىت توشقاندا ئوخشاش ئەسكەرتمە ئىجرا بولىدۇ.
3. **قىستۇرما ئېچىلغاندا:**
   - ئەگەر `pendingStartupReminder` بار بولسا، باش بەتنىڭ ئەڭ ئۈستىدە ئويۇق نېئومورفىزم ئەسكەرتمە كارتىسى چىقىدۇ؛ ئىشلەتكۈچى جاۋابىنى كۆرۈپ «ئوقۇپ چۈشەندىم» نى باسقاندا بەلگە تازىلىنىدۇ.

## 5. كۆرۈنمە يۈز يۆنىلىش خەرىتىسى (View State Machine)

قىستۇرما ئىچىدە 5 مۇستەقىل كۆرۈنۈش (`view`) بار:
1. `home` — باش بەت (كىتابلار تىزىملىكى + ئەسكەرتمە رامكىسى، مۇھىم سۆزلۈكلەر، مۇھىم ئەسكەرتىش، كىتاب قوشۇش، جىسون ئۈچۈن پرومپىت كۆچۈرۈش)
2. `study` — تاللانغان كىتابنىڭ 30 سوئال-جاۋاب ئۆگىنىش كۆرۈنمىسى
3. `vocabulary` — مۇھىم سۆزلۈكلەرنى كۆرۈش، سۈزۈش، ئىزدەش ۋە قوشۇش
4. `reminders` — مۇھىم ئەسكەرتىشلەر ۋە تور كۆرگۈچ ئەسكەرتمە تەڭشىكى
5. `add` — يېڭى كىتاب قوشۇش (JSON ھۆججەت يۈكلەش ياكى تېكىست چاپلاش)
