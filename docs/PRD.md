# مەھسۇلات تەلەپ ھۆججىتى (PRD) — «ئۆگىنىش قورالىم»

**ھۆججەت نۇسخىسى:** 1.0.0 (Enterprise Release)
**مەھسۇلات نامى:** ئۆگىنىش قورالىم (Chrome Manifest V3 قىستۇرمىسى)
**تىل ۋە يۆنىلىش:** ئۇيغۇرچە (`lang="ug"`, `dir="rtl"`)
**مەخپىيەتلىك دەرىجىسى:** نۆل ئىز قوغلاش، %100 يەرلىك ساقلاش (Zero Telemetry / Local-First)

---

## 1. قىسقىچە مەزمۇن ۋە مەقسەت

«ئۆگىنىش قورالىم» — ئوقۇغۇچىلار، تەتقىقاتچىلار ۋە ئۆزلىكىدىن بىلىم ئۆگەنگۈچىلەرنىڭ ھەر قانداق كىتاب ياكى دەرسلىكتىن ئېلىنغان **30 تەپسىلىي ۋە ئەڭ مۇھىم سوئال-جاۋاب**، **مۇھىم سۆزلۈكلەر** ۋە **مۇھىم ئەسكەرتىشلەر** نى JSON شەكلىدە ساقلاپ، تور كۆرگۈچنىڭ ئۆزىدىلا تەكرارلاپ ئىگىلىشىگە ياردەم بېرىدىغان كەسپىي Chrome قىستۇرمىسىدۇر.

قىستۇرما ھېچقانداق سۈنئىي ئەقىل مۇلازىمېتىرىغا ياكى تاشقى تور بېكەتكە باغلانمايدۇ. ئىشلەتكۈچى قىستۇرما ئىچىدىكى بىرلا كۇنۇپكا ئارقىلىق مەخسۇس تەييارلانغان پرومپىتنى كۆچۈرۈپ، ئۆزى خالىغان سۈنئىي ئەقىل مودېلىغا كىتاب مەزمۇنى بىلەن بىللە بېرىدۇ؛ مودېل چىقىرىپ بەرگەن JSON نى قىستۇرمىغا يۈكلىگەندىن كېيىن، شۇ كىتاب مەڭگۈلۈك يەرلىك ساقلىنىپ، تور كۆرگۈچ ئېچىلغاندا ئاپتوماتىك ئەسكەرتىپ تۇرىدۇ.

## 2. مەسىلە بايانى ۋە ھەل قىلىش چارىسى

| مەسىلە | «ئۆگىنىش قورالىم» نىڭ ھەل قىلىش چارىسى |
| --- | --- |
| كىتاب ئوقۇغاندىن كېيىن مۇھىم نۇقتىلارنىڭ تېز ئۇنتۇلۇپ كېتىشى | ھەر بىر كىتابتىن ئەڭ يادرولۇق 30 سوئال-جاۋاب ۋە ئۆزلەشتۈرۈش بەلگىسى بىلەن تەكرارلاش سىستېمىسى |
| سۈنئىي ئەقىلگە ھەر قېتىم توغرا JSON فورماتىدا پرومپىت يېزىشنىڭ ئاۋارىچىلىقى | بىر چېكىش بىلەن كۆچۈرۈلىدىغان، قاتتىق قۇرۇلمىلىق ئۇيغۇرچە پرومپىت قېلىپى |

| شەخسىي ئۆگىنىش مەلۇماتلىرىنىڭ بۇلۇتقا ياكى نازارەت مۇلازىمېتىرلىرىغا كېتىپ قېلىش خەۋپى | %100 يەرلىك ساقلاش، تاشقى تور ئۇلىنىشى پۈتۈنلەي چەكلەنگەن (`connect-src 'none'`) قۇرۇلما |

## 3. نىشان ئىشلەتكۈچىلەر ۋە ئىشلىتىش سىنارىيەلىرى

1. **شەخسىي ئۆگەنگۈچىلەر:** دىنىي، تارىخىي، پەن-تېخنىكا ياكى تىل كىتابلىرىدىن 30 مۇھىم سوئال-جاۋاب تەييارلاپ، كۈندە Chrome ئاچقاندا 2–3 مىنۇت تەكرارلاش.
2. **ئوقۇغۇچى ۋە تەتقىقاتچىلار:** ھەر بىر دەرسلىك ياكى ماقالىنى ئايرىم كىتاب سۈپىتىدە ساقلاپ، «مۇھىم سۆزلۈكلەر» ۋە «مۇھىم ئەسكەرتىش» بۆلۈملىرىدە تېز ئىزدەش.
3. **مەخپىيەتلىككە ئەھمىيەت بېرىدىغان ئىشلەتكۈچىلەر:** ھېچقانداق ھېسابات ئاچماي، تورغا باغلانماي تۇرۇپ تولۇق بىخەتەر شەخسىي بىلىم ئامبىرى قۇرۇش.

## 4. يادرولۇق فۇنكسىيەلىك تەلەپلەر (Functional Requirements)

### FR-01: سۈنئىي ئەقىل ئۈچۈن JSON پرومپىت كۆچۈرۈش
- باش بەتنىڭ ئاستىدا بىرلا ئاساسىي توق كۆك كۇنۇپكا بولىدۇ: **«جىسون ئۈچۈن پرومپىت كۆچۈرۈش»**.
- باسقاندا مەخسۇس تەييارلانغان پرومپىت سىستېما كۆچۈرۈش تاختىسىغا (Clipboard) كۆچۈرۈلىدۇ ۋە ئوڭۇشلۇق ئۇچۇر كۆرۈنىدۇ.
- پرومپىت ھەر قانداق سۈنئىي ئەقىل مودېلىدىن:
  1. كىتاب/دەرسلىك نامى (`bookTitle`)،
  2. دەل **30 دانە تەپسىلىي ۋە ئەڭ مۇھىم سوئال-جاۋاب** (`questions`)،
  3. **مۇھىم سۆزلۈكلەر** (`vocabulary`)،
  4. **مۇھىم ئەسكەرتىشلەر** (`reminders`)
  نى ساپ JSON شەكلىدە، ساپ ئۇيغۇرچە ۋە توغرا ئاتالغۇ ئۆلچىمى بىلەن چىقىرىپ بېرىشنى تەلەپ قىلىدۇ.

### FR-02: كىتاب قوشۇش ۋە JSON يۈكلەش
- باش بەتتە **«كىتاب قوشۇش»** كۇنۇپكىسى بولىدۇ.
- ئىشلەتكۈچى ئىككى ئۇسۇلدا JSON كىرگۈزەلەيدۇ:
  - `.json` ھۆججىتىنى كومپيۇتېردىن تاللاپ يۈكلەش،
  - ياكى سۈنئىي ئەقىل چىقىرىپ بەرگەن JSON تېكىستىنى بىۋاسىتە چاپلاش (تېكىست ئىچىدىكى Markdown كود رامكىسى ```json ئاپتوماتىك تازىلىنىدۇ).
- كىتاب نامى JSON ئىچىدىن ئاپتوماتىك ئوقۇلىدۇ، ئىشلەتكۈچى خالىسا ئۆزگەرتەلەيدۇ.
- بىر قېتىم ساقلانغان كىتاب تور كۆرگۈچ تاقالسىمۇ، كومپيۇتېر قايتا قوزغالسمۇ يوقاپ كەتمەيدۇ (`chrome.storage.local`).

### FR-03: مۇستەقىل كىتابلار تىزىملىكى ۋە ئايرىم ئەسكەرتمە كونترولى
- باش بەتتىكى ئاساسىي كارتىدا بارلىق ساقلانغان كىتابلار تەرتىپ نومۇرى بىلەن (`1.`, `2.`, `3.`) ئايرىم كۆرۈنىدۇ.
- ھەر بىر كىتاب قۇرىنىڭ ئوڭ تەرىپىدە كىتاب نامى ۋە ئىگىلەش ئەھۋالى، سول تەرىپىدە بولسا شۇ كىتابقا خاس **«ئەسكەرتمە»** تاللاش رامكىسى بولىدۇ.
- ئىشلەتكۈچى خالىغان كىتابنىڭ ئەسكەرتمىسىنى ئېچىپ ياكى ئۆچۈرۈپ قويالايدۇ.

### FR-04: سوئال-جاۋاب ئۆگىنىش كۆرۈنمىسى
- كىتاب نامىنى باسقاندا شۇ كىتابنىڭ مەخسۇس ئۆگىنىش بېتى ئېچىلىدۇ.
- سوئاللارنى تاللاش سۈزگۈچى: **ھەممىسى** | **ئۆگىنىلمىگەن** | **ئىگىلىگەن**.
- ھەر بىر كارتىدا سوئال كۆرۈنىدۇ؛ **«جاۋابنى كۆرۈش»** نى باسقاندا تەپسىلىي جاۋاب ئېچىلىدۇ.
- ئىشلەتكۈچى **«ئۆگەندىم»** ياكى **«قايتا كۆرىمەن»** دەپ بەلگە قويالايدۇ، ئىلگىرىلەش دەرھال ساقلىنىدۇ.
- ئالدىنقى/كېيىنكى سوئالغا ئۆتۈش، كىتابنى JSON زاپاس چۈشۈرۈش ۋە كىتابنى ئۆچۈرۈش (ئىككى باسقۇچلۇق جەزملەشتۈرۈش بىلەن) ئىقتىدارى بار.

### FR-05: مۇھىم سۆزلۈكلەر بۆلۈمى
- باش بەتتىكى **«مۇھىم سۆزلۈكلەر»** بۆلىكى ئارقىلىق بارلىق كىتابلاردىكى مۇھىم ئاتالغۇ ۋە سۆزلۈكلەرنى كۆرۈش، كىتاب بويىچە سۈزۈش، ئىزدەش ۋە يېڭى سۆزلۈك قوشۇش مۇمكىن.

### FR-06: مۇھىم ئەسكەرتىش ۋە تور كۆرگۈچ ئېچىلغاندا ئەسكەرتىش سىستېمىسى
- باش بەتتىكى **«مۇھىم ئەسكەرتىش»** بۆلىكى ئارقىلىق:
  - ئومۇمىي ئەسكەرتمە سىستېمىسىنى ئېچىپ-ئۆچۈرۈش (تور كۆرگۈچ ئېچىلغاندا چىقسۇن ياكى چىقمىسۇن)،
  - قەرەللىك ئەسكەرتىش ئارىلىقىنى تەڭشەش (پەقەت تور كۆرگۈچ ئېچىلغاندا، ھەر 1 سائەتتە، ھەر 3 سائەتتە، ئۆچۈرۈش)،
  - كىتابلاردىكى مۇھىم ئەسكەرتىش ۋە خۇلاسە پىكىرلەرنى كۆرۈش ھەم يېڭى ئەسكەرتىش قوشۇش،
  - ئەسكەرتىش ئۇقتۇرۇشىنى دەرھال سىناپ كۆرۈش مۇمكىن.
- تور كۆرگۈچ يېڭىدىن ئېچىلغاندا (`chrome.runtime.onStartup`)، ئەگەر ئومۇمىي ئەسكەرتمە ئوچۇق بولۇپ، ئەڭ ئاز دېگەندە بىر كىتابنىڭ «ئەسكەرتمە» رامكىسى تاللانغان بولسا، قىستۇرما سىستېما ئۇقتۇرۇشى چىقىرىدۇ ھەمدە قىستۇرما بەلگىسىگە (`!`) نىشان قويىدۇ.

## 5. فۇنكسىيەدىن سىرتقى تەلەپلەر (Non-Functional Requirements)

1. **بىخەتەرلىك ۋە مەخپىيەتلىك (NFR-01):**
   - نۆل ئىز قوغلاش (Google Analytics ياكى ھەر قانداق تاشقى ئانالىز قەتئىي يوق).
   - خىتاي شىركەتلىرى (Baidu, Tencent, Alibaba قاتارلىقلار) ۋە ھەر قانداق تاشقى CDN ياكى API دىن %100 خالىي.
   - قاتتىق MV3 CSP: `connect-src 'none'` ئارقىلىق ھەر قانداق تور چىقىشىنى تور كۆرگۈچ قاتلىمىدا توسۇش.
   - ئەڭ ئاز ئىجازەت پرىنسىپى: پەقەت `storage`، `notifications`، `alarms`. `<all_urls>` ياكى `tabs` رۇخسىتى تەلەپ قىلىنمايدۇ.
2. **ئاتالغۇ ۋە ئەخلاقىي ئۆلچەم (NFR-02):**
   - بارلىق كۆرۈنمە يۈز، ئۇچۇر، پرومپىت ۋە ھۆججەتلەردە ساپ ئۇيغۇرچە، توغرا مىللىي ئاتالغۇ ۋە ئەھلى سۈننەت ئەخلاقىغا ئۇيغۇن ئىلمىي ئۇسلۇب قوللىنىلىدۇ.
3. **ئۇسلۇب ۋە قولايلىق (NFR-03):**
   - `design/style.md` دا بەلگىلەنگەن يورۇق يۇمشاق نېئومورفىزم، `dir="rtl"`، `letter-spacing: 0`، WCAG AA سېلىشتۇرما ۋە `prefers-reduced-motion` ئۆلچىمىگە تولۇق ئەمەل قىلىش.
4. **ئىقتىدار ۋە ئىشەنچلىكلىك (NFR-04):**
   - قىستۇرما كۆزنىكى `< 100ms` ئىچىدە ئېچىلىشى كېرەك.
   - بارلىق ساقلاش، ئوقۇش، JSON تەھلىل قىلىش ۋە كۆچۈرۈش مەشغۇلاتلىرى `try/catch` بىلەن قوغدىلىشى شەرت.

## 6. قوبۇل قىلىش ئۆلچەملىرى (Acceptance Criteria)

- [ ] قىستۇرما پەقەت 3 ھۆججەت (`manifest.json`, `popup.html`, `popup.js`) بىلەن Chrome غا «Load unpacked» قىلىنغاندا بىرمۇ خاتالىق ياكى ئاگاھلاندۇرۇش چىقماسلىقى كېرەك.
- [ ] پرومپىت كۆچۈرۈش كۇنۇپكىسى بېسىلغاندا 30 سوئال-جاۋاب + سۆزلۈك + ئەسكەرتىش پرومپىتى كۆچۈرۈلۈشى كېرەك.
- [ ] JSON يۈكلەنگەندە كىتاب ئايرىم ساقلىنىپ، Chrome نى تاقاپ قايتا ئاچقاندىمۇ ساقلىنىپ تۇرۇشى كېرەك.
- [ ] ھەر بىر كىتابنىڭ «ئەسكەرتمە» تاللاش رامكىسى ۋە ئومۇمىي ئەسكەرتمە تەڭشىكى مۇستەقىل ئىشلىشى كېرەك.
- [ ] Network كۆزنىكىدە 0 دانە تاشقى تور تەلىپى كۆرۈنۈشى كېرەك.
